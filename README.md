# Party HUD

Standalone Fabric client mod extracted from `untitled` for Minecraft 1.21.4.

## Features

- Unlimited saved party targets in both Compact and Detail modes
- Dynamic multi-column wrapping so every saved target is rendered
- Team / Enemy / Neutral colors
- Distance, vertical delta, health, armor, sneaking and direction display
- Player head rendering and short last-seen position memory
- Drag-and-drop HUD editor and persistent JSON settings

## Commands

- `/party <player>`
- `/party <player> team`
- `/party <player> enemy`
- `/party <player> neutral`
- `/party remove <player>`
- `/party clear`
- `/party sort order|distance|health`
- `/party mode compact|detail`
- `/hud`
- `/hud reset`
- `/partyhud`
- `/partyhud reset`

Settings are stored in `config/partyhud.json`.
